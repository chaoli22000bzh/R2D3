R2D3 : couverture Wi-Fi multibornes

Premier laboratoire de conception radio 3D simplifiée, 3 étages et 3 bornes

Objectif

Place les trois bornes dans un bâtiment de trois niveaux pour couvrir tous les points de contrôle. Les bornes couvrent aussi les étages voisins, avec une atténuation pédagogique entre planchers.

Les points de contrôle sont fixes. Les cercles montrent uniquement une portée illustrative, le résultat est calculé par le moteur commun selon les positions 3D.

Placement des bornes

Clique sur le plan pour déplacer AP-01 au niveau affiché.
